# EDI Resolve AI

AI-powered EDI transaction discrepancy detection and resolution.

## SpartHill Hacks 2026 - IBM AI Challenge

EDI Resolve AI helps retailers and suppliers identify mismatches
between electronic purchase orders and invoices.

## MVP Features

1. Import EDI 850 purchase orders and EDI 810 invoices.
2. Parse EDI documents into structured data.
3. Detect price, quantity, UOM, and product identifier mismatches.
4. Use AI to explain discrepancies and recommend resolutions.
5. Display exceptions in a human-review dashboard.
